# Рыбалка на озере — 3D-симулятор рыбалки

Полностью играбельная 3D-игра про рыбалку на тихом лесном озере. Сделана на **Next.js (App Router) + TypeScript + Three.js**. Весь интерфейс — на русском языке.

Всё в игре генерируется процедурно: 3D-сцена, модели шести видов рыб, звук (Web Audio), окружение. Никаких внешних ассетов, API-ключей и бэкенда.

## Быстрый старт

```bash
npm install
npm run dev
```

Откройте http://localhost:3000

Продакшен-сборка:

```bash
npm run build
npm start
```

Требуется Node.js 18+.

## Как играть

### Управление (мышь и клавиатура)

| Действие | Управление |
| --- | --- |
| Обзор | движение/перетаскивание мыши |
| Замах и заброс | удерживать **ЛКМ**, отпустить — заброс |
| Подсечка при поклёвке | **ЛКМ** в момент «ПОДСЕКАЙТЕ!» |
| Подмотка в борьбе | удерживать **ЛКМ** |
| Ослабить натяжение | отпустить ЛКМ |
| Фрикцион | колесо мыши или кнопки «−/+» |
| Вымотать снасть | кнопка «Вымотать снасть» |
| Пауза | **Escape** |
| Отмена замаха | правая кнопка мыши |

На сенсорных экранах появляются экранные кнопки для заброса, подсечки и подмотки.

### Игровой цикл

Выбрать наживку → прицелиться → замах и заброс → ждать поклёвку → подсечь вовремя → вываживать рыбу → осмотреть улов → оставить или отпустить → улучшать снасти.

### Подсказки

- **Рано подсекли** — рыба испугается и уйдёт, придётся ждать заново.
- **Поздно** — рыба утащит наживку.
- В борьбе следите за натяжением: зелёная зона — безопасно, жёлтая — рискованно, красная — возможен обрыв лески. При рывках ослабляйте фрикцион, при подмотке можно прибавить.
- Садок заполнен — отпускайте рыбу или продавайте улов в магазине.

### Зоны ловли

Дистанция заброса определяет зону: **у камышей** (мелко), **открытая вода**, **глубина**. В разных зонах клюют разные виды рыб: щука и карась — у камышей, лещ — на глубине, карп — на открытой воде и на глубине.

### Виды рыб

Карась, Плотва, Окунь, Лещ, Карп, Щука. У каждого вида — свой 3D-вид, предпочтения по наживке, зоне и времени суток, вес, сила сопротивления и цена. Чем ближе к трофею — тем тяжелее вываживание.

### Наживки

Червь, Опарыш, Кукуруза, Живец. У каждой — свои предпочтения по рыбе. Подходящая наживка ускоряет поклёвку.

## Возможности

- Полный цикл ловли: замах, заброс по дуге со всплеском, поклёвка, подсечка, интерактивное вываживание с фрикционом, натяжением и выносливостью рыбы.
- Ускоренный цикл суток (сутки ≈ 24 минуты) с меняющимся освещением; погода и активность рыбы зависят от времени.
- Садок, продажа улова, магазин (наживки, леска, удилища, садок), опыт, уровни, личные рекорды и история.
- Сохранение прогресса в localStorage, восстановление при загрузке.
- Процедурный звук: всплески, катушка, поклёвки, птицы (Web Audio), отключается в настройках.
- Настройки: звук, громкость, чувствительность мыши, качество графики.

## Структура проекта

```
app/                    Next.js App Router (layout, page, стили)
components/             React-интерфейс (HUD, панели, результат ловли, сенсорные кнопки)
lib/game/               Игровая симуляция (не зависит от Three.js)
  simulation.ts           Конечный автомат ловли, поклёвки, борьба, экономика
  data.ts                 Виды рыб, наживки, снасти, формулы
  terrain.ts              Форма озера, берега, зоны
  audio.ts                Процедурный звук (Web Audio)
  save.ts                 Сохранение/загрузка профиля
lib/three/              Рендеринг Three.js
  renderer.ts             Сцена: озеро, берег, деревья, удочка, леска, эффекты
  fishMesh.ts             Процедурные низкополигональные модели рыб
```

Симуляция тикает по delta time и полностью отделена от рендеринга и UI.

## Управление ресурсами

Three.js-ресурсы (геометрии, материалы, текстуры, WebGL-контекст) освобождаются при размонтировании, обработчики событий снимаются, симуляция останавливается.
