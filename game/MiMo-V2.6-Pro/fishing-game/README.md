# Рыбалка 3D — Озеро

3D симулятор рыбалки на озере в русской глубинке. Полностью рабочая игра на Next.js + TypeScript + Three.js.

## Установка и запуск

```bash
npm install
npm run dev
```

Откройте **http://localhost:3000** в браузере.

Для продакшн-сборки:

```bash
npm run build
npm start
```

## Управление

| Действие | Управление |
|---|---|
| Осмотреться | Перетаскивание мышью |
| Зарядить заброс | Зажать ЛКМ |
| Забросить | Отпустить ЛКМ |
| Подсечь рыбу | Клик ЛКМ во время поклёвки |
| Вываживать рыбу | Удерживать ЛКМ во время борьбы |
| Ослабить нагрузку | Отпустить ЛКМ во время борьбы |
| Регулировка фрикциона | Колесо мыши или кнопки +/- |
| Пауза | Escape |
| Вывести снасть | Кнопка «Вывести снасть» |

## Игровой цикл

1. Выберите наживку (червь, опарыш, кукуруза, живец)
2. Прицельтесь и забросьте снасть
3. Дождитесь поклёвки (следите за поплавком)
4. Подсеките в нужный момент
5. Вываживайте рыбу, контролируя натяжение
6. Решите: оставить или отпустить
7. Продавайте рыбу, покупайте снасти, улучшайтесь!

## Зоны рыбалки

- **Мелководье** (< 15 м) — карась, плотва
- **Открытая вода** (15–35 м) — окунь, щука
- **Глубина** (> 35 м) — лещ, карп

## Виды рыб

Карась, Плотва, Окунь, Лещ, Карп, Щука — у каждого свои предпочтения по наживке, зоне и времени суток.

## Сохранение

Прогресс автоматически сохраняется в localStorage. При перезагрузке страницы всё сохраняется.
